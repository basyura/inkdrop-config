# 選択中ノートの左側に色付きの線を表示する

## 修正案

- `styles.css` の `.note-list-bar-layout` 内に、選択中のノートだけを対象とするスタイルを追加する。
- 左端に幅 3px、既存スタイルでも使われている `#facf4e` の線を表示する。
- ノートの幅や文字位置が変わらないよう、内側の `box-shadow` を使用する。
- 文字列・アイコンの縦位置を維持するため、`border`、`padding`、`margin`、`height`、`line-height`、配置関連のプロパティは変更しない。
- 対象セレクターは、起動中の Inkdrop の DOM と計算済みスタイルを確認して確定する。

## 作業手順

1. 未保存の編集が保存済みであることを確認し、Inkdrop をローカル限定のデバッグ接続を有効にして再起動する。
2. 選択中・未選択のノートのクラスと既存スタイルを確認する。
3. 修正案の了承後、`styles.css` にスタイルを追加する。
4. 選択中ノートの左端に線が表示され、未選択ノートには表示されないことを確認する。
   - 適用前後でノート行・文字列・アイコンの位置と寸法を比較し、特に縦位置が変化しないことを確認する。
5. `git diff --check` を実行する。

## 実施結果

- リモートデバッグ接続を使用せず、起動中の Inkdrop の DevTools コンソールで DOM と計算済みスタイルを確認した。
- 選択中ノートのクラスは `.note-list-item-view.active`。変更前の `box-shadow` は `none`。
- `styles.css` に `box-shadow: inset 3px 0 0 #facf4e` を追加した。ファイル保存による自動反映を確認した。
- 表示中の 9 行について、行・見出し・メタ情報・アイコンの位置と寸法が適用前後で完全に一致した。
- 選択中ノートの計算済みスタイルに黄色の内側の影が付き、未選択ノートの `box-shadow` はすべて `none` のままであることを確認した。
- 実画面で左端の黄色い線を確認し、調査用の DevTools を閉じた。
- `git diff --check` で問題がないことを確認した。
